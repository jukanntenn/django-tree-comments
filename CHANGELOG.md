## [0.0.4rc1] - 2026-08-02

First release candidate. A threaded comments app for Django, powered by
recursive CTE queries — single-query tree fetching, HTMX-friendly fragment
responses, built-in moderation, JSON API, and i18n out of the box.

Requires Django 5.2+ and Python 3.10+.
